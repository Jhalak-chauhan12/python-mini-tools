Python Mini Tools

This is a beginner-friendly Python project containing two command-line tools.

1. Number Guessing Game
Generates a random number between 1 and 100.
Allows users to guess the secret number.
Counts the number of attempts.
Gives points based on correct guesses.
Handles invalid input.
2. Word Frequency Analyzer
Reads a text file.
Counts how many times each word appears.
Uses a dictionary to store word counts.
Sorts words by frequency.
Displays the 10 most common words.
Scoring System
Starting score: 100 points.
Every incorrect valid guess reduces 10 points.
Minimum score: 0 points.
Invalid inputs do not reduce points.

How to Run
Download the project files.
Open the project folder in VS Code or terminal.
Run the following command:

python main.py

Select an option from the menu.
